# RichText-to-Pixiv Novel Formatter

I create this because I want to upload my fanfic on Pixiv with rich text without a hassle. They now only allow  bold/italics text in their novel formatting. By putting bold/italics text inside their spacial tag, Pixiv can display the input text as the original be. But doing it manually is too tedious for me. So I did this formatter with the help of Google's AI in their search engine :D

You can try it now:
